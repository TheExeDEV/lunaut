# Editors

lunaut is a plain LSP server: `lunaut lsp` speaks JSON-RPC over stdio. VS Code has a full extension; every other editor only needs to start the binary.

| Editor | Folder | What to do |
| --- | --- | --- |
| VS Code | [`vscode/`](vscode) | Install [Lunaut from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=theexe.lunaut-luau), or `lunaut.vsix` from a release (the installers do it for you) |
| Neovim 0.11+ | [`neovim/lunaut.lua`](neovim/lunaut.lua) | Copy into `~/.config/nvim/plugin/` or `require` it from your config |
| Helix | [`helix/languages.toml`](helix/languages.toml) | Merge into `~/.config/helix/languages.toml` (or `.helix/languages.toml` in a project) |
| Zed | [`zed/`](zed) | Install the **Lunaut** extension: it highlights Luau and downloads the server from the latest release. Remove the **Luau** extension if it is installed, both define the Luau language. Without the extension, merge [`zed/settings.json`](zed/settings.json) into Zed's settings to run lunaut in place of the luau-lsp binary |

## Settings outside VS Code

The server reads `.vscode/settings.json` in the project root by itself, so the same file works in every editor. Settings sent by the editor in `initializationOptions` win over the file. Use the flat VS Code form:

```json
{
	"vscode": {
		"lunaut.fflags.override": { "LuauSolverV2": "true" },
		"lunaut.rojo.projectFile": "default.project.json"
	}
}
```

`luau-lsp.*` keys work too; `lunaut.*` wins when both are set.

## What only VS Code has

- `rojo sourcemap --watch` runs inside the extension. Other editors get the sourcemap regenerated by the server on file changes (`lunaut.rojo.autogenerate`).
- The Studio companion plugin talks to an HTTP server hosted by the extension.
- Command palette entries such as *Lunaut: Show FFlags* are VS Code UI. Other editors get **Lunaut: Show Status** and **Lunaut: Regenerate Rojo Sourcemap** in the code actions menu (`Ctrl+.` in Zed, `vim.lsp.buf.code_action()` in Neovim); restarting the server is the editor's own command, for example `editor: restart language server` in Zed. The rest is available through the [custom LSP methods](../README.md#custom-lsp-methods).
- `end` is inserted through `textDocument/onTypeFormatting` when you press Enter, so the editor has to support on-type formatting (Zed and VS Code do; in Neovim it needs a plugin that sends it).
